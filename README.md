Bertindaklah sebagai Principal Fullstack Developer dan Lead UI/UX Architect senior. Kamu sangat berpengalaman dalam membangun website performa tinggi menggunakan HTML5, CSS3, dan Vanilla JavaScript murni tanpa dependensi eksternal.

[PROJECT SPECIFICATION]
Buatkan kode lengkap untuk website personal portfolio interaktif:
1. Nama Pemilik: Deni Hartono
2. Peran/Profesi: Web Designer & Senior Web Analyst
3. Aesthetic & UI Style: Terinspirasi dari Programmer Zaman Now ([https://www.programmerzamannow.com/](https://www.programmerzamannow.com/)).
   - Dark mode default (#0f172a / #0a0e17) dengan aksen warna kontras/neon (Emerald/Cyan/Yellow).
   - Layout clean, modern, berbasis grid/card dengan border halus dan efisiensi ruang tinggi.
   - Tipografi yang sangat readable (system-ui & monospace accents untuk kesan tech/analyst).

[STRUCTURAL SECTIONS]
- Sticky Header/Navbar (Brand + Navigation Links + Mobile Toggle Menu).
- Hero Section (Big Title, Dual Role Badge, Short Elevator Pitch, CTA "Lihat Portofolio" & "Hubungi Saya").
- About & Skills Section (Highlight perpaduan Web Design/UI UX + Data Analysis/SEO/Web Performance).

- Contact Section (Clean Form + Social Media Links).

[STRICT TECHNICAL CONSTRAINTS]
1. ZERO LIBRARIES: Dilarang menggunakan Tailwind, Bootstrap, jQuery, React, FontAwesome, atau CDN/library JS/CSS apa pun. Gunakan Native Web API & Pure CSS.
2. CLEAN ARCHITECTURE: 
   - Gunakan HTML5 Semantic Tags.
   - Gunakan CSS Variables (:root) untuk theme, spacing, & color management.
   - Gunakan CSS Grid & Flexbox secara efisien. Responsif penuh (Mobile, Tablet, Desktop).
   - Gunakan Vanilla JS murni (Smooth scroll, Mobile Navigation Toggle, Portfolio Filtering).
3. NO PLACEHOLDERS / NO CUTS: Dilarang keras menggunakan komentar seperti "// kode sisanya di sini", "...code continues...", atau memotong fungsi. Semua CSS, HTML, dan JS HARUS ditulis lengkap 100%.
